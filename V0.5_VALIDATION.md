# v0.5 Independent Commander Validation

## Scope

This migration was applied incrementally to the existing `0.6.0` working tree. The product brand remains Codex Boss; the original interactive control surface is renamed **Controller**. Existing Electron, React, provider session, Council, evidence, artifact-integrity, history, launcher, and security boundaries were retained.

## Implemented modules

- `electron/runtimes/runtime.ts`: provider-neutral Runtime contract and exhaustive availability handling.
- `electron/runtimes/codex/codex-cli-runtime.ts`: Codex CLI health, execute, cancel, failure classification, and evidence review as an ordinary Runtime.
- `electron/runtimes/web/provider-runtime-adapter.ts`: common web Runtime boundary.
- `electron/commander/*`: Main Commander, task state machine, Runtime Registry, Scheduler, Role Router, Budget Manager, Context Manager, Execution Gate, and runtime-policy validation.
- `.codex-boss/config/runtime-policy.json`: credential-free default routing policy with JSON Schema.
- `electron/provider-automation.ts`: all waiting providers are observed/captured concurrently with `Promise.allSettled`; overlapping monitor ticks are blocked; the existing strict commit barrier remains.
- `src/renderer/main.tsx`: Controller naming, Runtime Status, enable/priority controls, and Role Routing preference/fallback controls.

## Known limitations

- API and local-model Runtime implementations remain explicit future/stub scope; the existing Work API transport remains available through the preserved provider automation path.
- Runtime availability for visible web sessions is currently derived from whether its isolated provider view is open; richer periodic page health telemetry remains future work.
- Existing task JSON and evidence identifiers are preserved. New runtime/role fields are defaulted during read and persisted on the next state mutation.
- The deprecated `.codex-controller/` runtime-data directory is ignored and not deleted automatically; new Codex Runtime output uses the application data runtime directory.
