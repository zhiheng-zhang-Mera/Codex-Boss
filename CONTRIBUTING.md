# Contributing

This repository is an early development starter. Keep pull requests small, evidence-linked, and reversible.

1. Create a focused branch and describe the contract being changed.
2. Add or update tests for observable behavior.
3. Run `python -m unittest discover -s tests -v` locally.
4. Update `README.md` for user-facing changes and `STRUCTURE.md` for boundary or dependency changes.
5. Do not commit credentials, personal data, copyrighted game assets, private model transcripts, or real health records.

Design documents describe intended architecture. A merged design is not evidence that the behavior is implemented or validated.
