## 1. What the change is

One comment in `.github/workflows/ci.yml` (lines 23–33) tells a reader where the three frozen Phase 01–05
gates run. After the v1.2 seal — `PF-DEBT-016` `FIXED` by the private control plane, and the public
`platform-qualification.yml` reduced to a hosted DIAGNOSTIC lane — the sentence is false:

```text
- # the `test:platform-qualification` tier and run in `Platform Qualification`
- # (`.github/workflows/platform-qualification.yml`, `workflow_dispatch`), which generates each declared
- # prerequisite with its own official generator first. Nothing was skipped or weakened — measured on run
+ # the `test:platform-qualification` tier and run on the real soak host, by the qualification workflow in the
+ # separate PRIVATE control repository `Boss-Qualification-Control` (`workflow_dispatch`, main-only), which
+ # generates each declared prerequisite with its own official generator first. No workflow in this repository
+ # runs the tier: `.github/workflows/platform-qualification.yml` is a hosted DIAGNOSTIC lane that states
+ # `HOSTED_RUNNER_NOT_A_QUALIFICATION_HOST` instead of claiming a qualification. Nothing was skipped or
+ # weakened — measured on run
```

and the sentence that describes what `tests/unit/test-layers.test.ts` enforces:

```text
- # qualification producer, and the qualification workflow may not be reachable from push. The graduation step
+ # qualification producer, and no workflow in this repository may run the qualification tier. The graduation step
```

**No executable line changes.** Not a step, not a trigger, not a permission, not a threshold, not an
assertion. The whole diff is comment text inside `ci.yml`.

## 2. Why it needs the Owner

`ci.yml` is Root Trust Surface by name: `PLAN_SECTION_3_ROOT_TRUST_PATHS` lists `.github/workflows/ci.yml`,
and `classifySurface(".github/workflows/ci.yml")` returns `ROOT_TRUST_SURFACE`. The trust model therefore
treats an edit to it as a change that may only be authorised externally — the same rule that made the
epoch-22 lockdown itself an Owner-authorised promotion.
